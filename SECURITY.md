# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** containing exploitation instructions, credentials, or details of an unpatched vulnerability.

Where available, use the affected repository's **Security → Report a vulnerability** feature to submit a private advisory. If that option is unavailable, contact the maintainers through an established private channel and ask for a secure reporting method before sending sensitive details.

Include a concise description, affected versions or components, steps to reproduce, potential impact, and any suggested mitigation you can safely share.

## Scope and response

Security support and response timelines vary by project. Refer to the affected repository for supported versions and project-specific disclosure practices. Please allow time for maintainers to investigate before public disclosure.

Never send passwords, private keys, or access tokens as part of a report.
